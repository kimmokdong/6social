## 남은 문제와 제안 — 내용/그림은 수정하지 않음

1. **중간 · 권한 요약의 사실 정확성**: `js/game.js`의 기존 A5 요약 ‘법관 임명에 동의해요’, G5 요약 ‘국회 동의로 법관을 임명해요’는 일반 법관까지 국회 동의·대통령 임명 대상처럼 읽힙니다. `data.js` 수첩 원문처럼 **대법원장·대법관**으로 범위를 명확히 하는 것을 제안합니다. 헌법 제104조는 일반 법관의 임명 절차를 별도로 정합니다. [국가법령정보센터 대한민국헌법 제104조](https://law.go.kr/LSW/lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=19880225&joNo=000800&lsiSeq=61603&urlMode=lsInfoP)
2. **낮음 · 공개 재판의 예외**: C6 수첩과 획득 요약은 공개 원칙을 설명하지만 예외가 빠져 있습니다. ‘재판은 원칙적으로 공개해요’처럼 단정 범위를 줄이는 것을 제안합니다. 헌법 제109조에는 일정한 사유에 따른 비공개 심리 예외가 있습니다. [헌법재판소 대한민국 헌법](https://ccourt.go.kr/common/board/Download.do?bcIdx=992137&cbIdx=1140&streFileNm=045de1de-14ad-4fa1-af12-bf498e90a67e.pdf)
3. **낮음 · 어려운 말/법률 절차의 단순화**: ‘심리’, ‘제청’, ‘항소’, ‘무역 협정’은 수업에서 짧은 풀이를 보완하면 좋겠습니다. 3심을 같은 재판 세 번으로 이해하지 않도록 상고심은 법률상 문제를 다룬다는 설명을 수업에서 보완할 수 있습니다. 대통령 선택 ‘서명하기’도 법률 ‘공포’와 연결해 설명하면 좋습니다. [대법원 어린이 사법부 소개](https://www.scourt.go.kr/kids/about/about_intro/index.html)
4. **낮음 · 아트 스타일**: 인물/배경의 수채화풍 그림과 단색 SVG 건물/게이지의 스타일 차이가 있습니다. 잘림·찌그러짐은 발견하지 않았으며, 원본 그림과 공용 아트는 수정하지 않았습니다. 그림 로드 실패 시 SVG로 전환되어도 위치가 유지되는지 별도로 검사합니다.
5. **낮음 · 게임 밖의 404**: 루트 게임 목록의 `/favicon.ico`는 HTTP 404입니다. 이전 검사에서 목록으로 이동한 뒤 발생한 콘솔 오류는 게임 자체 오류와 구분했습니다. 루트 파일은 허용 범위 밖이므로 수정하지 않았습니다.

[대한민국헌법 제54조·제70조 등](https://law.go.kr/lsInfoP.do?docType=JO&joNo=001000&lsiSeq=61603), [헌법재판소 심판 안내](https://ecourt.ccourt.go.kr/files/PDF/USER_MANUAL_2.pdf)
