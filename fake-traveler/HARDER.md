# 가짜 여행자를 찾아라 — 난이도 올리기 (Codex 작업 지시)

## 왜
선생님 의견: "너무 쉽다." 분석 결과 **가짜 여행자 11명 모두 사진이 거짓**이다. 사진 줄만 훑어서 혼자 다른 풍경을 고르면 끝나서,
기온·한마디·짐을 읽고 생각할 필요가 없다. 사건 6~9는 가짜의 증거 4개 중 3개가 거짓이라 아무거나 눌러도 맞는다.
지금 증거 은행엔 **닮은 기후 둘 다에서 진짜인 '애매한 사진'이 거의 없다**(짝마다 0~1장).

## 목표 난이도 (퀴즈처럼 만들지 말 것 — 증거를 비교하며 추리하게)
선생님 결정: **수업에서 기후를 다 배운 뒤 복습으로 하는 게임이므로 사건 1부터 헷갈려야 한다.** 쉬운 연습 단계는 두지 않는다.
- **사건 1~10 모두**: 가짜는 주장한 기후와 **닮은 기후**(`climates[claim].confuse`)에서 온 사람만. **가짜의 사진은 '애매한 사진'**(두 기후 모두에서 볼 법한 풍경) → 사진만 봐서는 못 찾음.
  거짓은 기온·한마디·짐 중 **1~2개**에만 숨긴다. 진짜 여행자들의 함정 증거(진짜인데 이상해 보이는 것)는 사건마다 2개 이상.
- 사건 1의 조작 안내(어디를 누르는지)는 그대로 두되 내용은 위 기준대로. 사건 10은 가짜 2명.
- '정체 밝히기' 보기 3개는 서로 닮은 기후끼리(예: 사바나 가짜 → 사바나·스텝·열대우림). 한눈에 다른 기후(사막 사건에 툰드라 등)는 넣지 않는다.
- 무한 수사: 처음부터 애매한 사진·거짓 1~2개, 연속 기록이 쌓일수록 함정이 늘고 연속 5건부터 가짜 2명 가능.
- 애매한 사진을 의심하면 지금처럼 "앗! 진짜 증거야 — ○○에서도 볼 수 있어요"로 겹치는 특징을 배우게 한다(`okWhy`).

## 할 일
1. **애매한 사진 14장 이상**(모든 사건에 쓰이므로 짝마다 2장 이상) — 내장 image_gen 으로(코드/SVG/PIL 그리기 금지, 자르기·WebP 변환만 허용). 기존 `assets/img/scenes/*.webp` 를 먼저 열어 화풍·크기를 똑같이. 사람·글자 없음.
   닮은 기후 짝마다 2장(제안 — 더 좋은 장면이 있으면 바꿔도 됨, 단 두 기후 모두에서 **사실로 맞아야** 함):
   - 열대우림↔사바나: 비 갠 뒤 붉은 흙길과 웅덩이·초록 풀 / 뜨거운 햇볕 아래 초록 들판 가장자리의 나무 몇 그루
   - 열대우림↔고산(열대 고산): 구름이 낀 초록 산비탈과 안개 / 비에 젖은 큰 잎 식물 화분이 있는 마을 골목
   - 사바나↔스텝: 누렇게 마른 풀밭과 넓은 하늘 / 마른 풀을 뜯는 소 떼
   - 사막↔스텝: 자갈 섞인 마른 땅과 키 작은 덤불 / 뜨거운 낮의 흙먼지 길
   - 지중해성↔서안 해양성: 돌담 집과 꽃 핀 정원 / 작은 항구와 요트
   - 타이가↔툰드라: 눈 덮인 평원 끝의 침엽수 몇 그루 / 이끼 낀 바위와 낮은 덤불
   - 툰드라↔빙설: 눈과 얼음이 덮인 하얀 땅과 바위 / 얼어붙은 바닷가
2. `js/bank.js` 에 새 사진 등록: `tags` 는 두 기후의 `rules[..].allowed` 에 모두 들어 있는 것만(새 태그가 필요하면 추가하고 두 기후의 allowed 에 넣되, 다른 기후 판정이 틀어지지 않게), `home` 은 둘 중 하나, `okWhy` 는 "○○에서도 볼 수 있어요!"처럼 짧게. `Replay.verdict(사진, 두 기후)` 가 모두 'lie' 가 아니어야 함.
3. `js/data.js` 사건 1~10의 증거를 위 목표대로 바꾼다(가짜는 닮은 기후에서, 사진 → 애매한 사진, 거짓은 기온·한마디·짐 중 1~2개, 진짜 여행자에 함정 2개 이상, 보기 3개는 닮은 기후끼리). **사건마다 주장 기후와 여행자 이름·말투는 그대로.** 바꾼 내용을 표로 보고.
4. `js/replay.js` 생성기·검증기를 새 규칙으로(가짜 사진은 애매한 사진, 거짓 1~2개, 무한 수사의 연속 기록에 따른 난이도 단계). `replay-check.js` 2000판 검증이 통과해야 함.
5. 화면 문구는 바꾸지 않는다. 다만 사건 1 수사판에서 부엉이 힌트 한 줄 "사진만 보면 속아요! 기온·말·짐까지 살펴봐." (처음 한 번만).
6. **명탐정 모드**(여권 화면에 버튼, 처음부터 열림 — 복습용):
   - 무한 수사 생성기로 매번 새 사건(난이도는 무한 수사의 연속 3건 수준 이상). **증거 카드가 모두 뒤집힌 채** 시작(여행자 얼굴과 증거 종류 아이콘만 보임).
   - **무료로 열 수 있는 장수 = 여행자 수 + 1.** 다 쓰면 그다음부터는 **한 장 열 때마다 탐정 점수 −10**(처음 100점). 그래서 끝까지 못 푸는 일은 없고, 적게 열고 맞힐수록 점수가 높다.
   - 진짜 증거를 '수상해!' 하면 −20, 정체 밝히기에서 틀리면 −10(돋보기 대신 점수). 점수는 0 아래로 안 내려감.
   - 끝나면 등급 도장: 90~100 명탐정 · 70~89 탐정 · 40~69 견습 탐정 · 0~39 초보 탐정. 최고 점수와 명탐정 횟수 저장, 명탐정 배지 1개 추가.
   - 화면 위에 '무료 n장 남음' → 다 쓰면 '한 장에 −10' 을 크게. 설명은 아이콘·숫자 위주로 짧게.

## 완료 조건
- `node js/replay-check.js` 2000판 통과 + 새 지표 출력: 사건 1~10·무한 수사·명탐정 모드에서 '사진 줄만 보고 가짜를 고를 수 있는 판'(가짜 사진이 거짓인 판) = 0%.
- 명탐정 모드: 무료 장수를 다 쓴 뒤에도 계속 열어 반드시 풀 수 있는지, 점수·등급 계산이 맞는지 테스트.
- 사건 1~10과 명탐정 모드를 Playwright 로 직접 풀어 보기(정답 경로·틀린 경로), 1366×768·768×1024·390×844 스크린샷 `fake-traveler/check/` 에 저장하고 직접 확인. 콘솔 오류 0.
- 끝나면 새 사진 목록, 바꾼 사건 표, 검증 결과를 짧게 보고. 사용량 한도에 걸리면 멈추고 어디까지 했는지 보고.

## 건드리면 안 되는 것
다른 게임 폴더, `shared-art/`, 기존 그림 파일(새 파일만 추가), 저장 형식(localStorage 키 — 새 항목 추가는 가능, 기존 기록은 지워지지 않게).
