# 가짜 여행자 — '애매한 사진' 그리기 (Codex 작업 지시)

## 배경
게임의 본편이 **라이어 여행단**(`js/liar.js`, `js/liar-ui.js`)으로 바뀌었다. 라이어는 닮은 기후에서 왔고, 자기 손패 중 '주장한 기후에서도 통하는 카드'로 버틴다.
지금 증거 은행엔 두 기후 모두에서 진짜인 **사진이 거의 없어서**(짝마다 0~1장) 라이어가 사진을 낼 수 없다 → 사진 카드도 쓸 수 있게 애매한 사진을 추가한다.
(예전 `HARDER.md` 는 더 이상 쓰지 않음. 기존 사건 10개는 '탐정 연습' 모드로 그대로 둔다 — 고치지 말 것.)

## 할 일
1. **애매한 사진 14장 이상** — 내장 image_gen 으로(코드/SVG/PIL 그리기 금지, 자르기·WebP 변환만 허용). 기존 `assets/img/scenes/*.webp` 를 먼저 열어 화풍·크기를 똑같이. 사람·글자 없음.
   닮은 기후 짝마다 2장 이상(두 기후 모두에서 **사실로 맞아야** 함):
   - 열대우림↔사바나: 비 갠 뒤 붉은 흙길과 웅덩이·초록 풀 / 뜨거운 햇볕 아래 초록 들판 가장자리의 나무 몇 그루
   - 열대우림↔고산(열대 고산): 구름이 낀 초록 산비탈과 안개 / 비에 젖은 큰 잎 식물이 있는 마을 골목
   - 사바나↔스텝: 누렇게 마른 풀밭과 넓은 하늘 / 마른 풀을 뜯는 소 떼
   - 사막↔스텝: 자갈 섞인 마른 땅과 키 작은 덤불 / 뜨거운 낮의 흙먼지 길
   - 지중해성↔서안 해양성: 돌담 집과 꽃 핀 정원 / 작은 항구와 요트
   - 타이가↔툰드라: 눈 덮인 평원 끝의 침엽수 몇 그루 / 이끼 낀 바위와 낮은 덤불
   - 툰드라↔빙설: 눈과 얼음이 덮인 하얀 땅과 바위 / 얼어붙은 바닷가
2. `js/bank.js` 에 등록: `tags` 는 두 기후의 `rules[..].allowed` 에 모두 들어 있는 것만(새 태그가 필요하면 추가하되 다른 기후 판정이 틀어지지 않게), `home` 은 둘 중 하나, 필요하면 `okWhy`. `Replay.verdict(사진, 두 기후)` 가 모두 'lie' 가 아니어야 함. 각 기후 `gallery` 에도 추가(도감).
3. `node js/replay-check.js`(2000판)와 `node js/liar-check.js` 통과. liar-check 에서 '라이어 손패 후보 중 통하는 사진' 이 짝마다 1장 이상인지 확인하는 줄을 추가.
4. 라이어 여행단을 Playwright 로 1366×768·768×1024·390×844 에서 한 판 끝까지 하고 스크린샷 `check/` 에 저장, 새 사진이 카드로 나오는 장면 확인. 콘솔 오류 0.

## 건드리면 안 되는 것
다른 게임 폴더, `shared-art/`, 기존 그림 파일(새 파일만 추가), `data.js` 의 사건 10개, `liar.js`·`liar-ui.js` 의 규칙(사진 카드 표시가 깨질 때만 CSS 손질 가능), 저장 형식. 사용량 한도에 걸리면 멈추고 어디까지 했는지 보고.
