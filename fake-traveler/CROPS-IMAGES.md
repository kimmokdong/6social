# 작물 카드 그림 8장 (그림만)

가짜 여행자 게임에 '작물' 단서 카드가 새로 생긴다. 코드는 Claude가 따로 고치니 **그림 파일만** 만든다.

## 스타일
- 이미지 생성 도구를 쓴다. `IMAGES.md` 의 "Shared style" 문장을 모든 프롬프트 끝에 그대로 붙인다.
- 기존 짐 그림 `assets/img/items/*.webp` 와 같은 스티커 모양으로 만든다. 직접 몇 장 열어 보고 맞춘다.
  - 크림색 배경 `#F3E9D7`, 가운데에 작물 하나만 둔다. 사람·글자·테두리는 넣지 않는다.
- 12살이 160px 크기에서 바로 알아봐야 한다.

## 그림 목록 (id → 내용)
- `banana`: 초록 잎이 달린 노란 바나나 송이
- `cassava`: 껍질이 갈색이고 속이 흰 길쭉한 카사바 뿌리 몇 개와 잎
- `dates`: 갈색·주황 대추야자 열매 송이
- `wheat`: 황금빛 밀 이삭 묶음
- `olive`: 초록·검은 올리브 열매가 달린 잎 가지
- `orange`: 잎 달린 오렌지 두세 개
- `potato`: 흙 묻은 감자 몇 개
- `quinoa`: 붉고 노란 퀴노아 이삭과 낟알 조금

## 저장
- 원본 PNG: `fake-traveler/assets/raw/crops/`
- 결과: `fake-traveler/assets/img/crops/{id}.webp`, 256×256, 품질 85
- `fake-traveler/assets/img/manifest.json` 에 기존 항목 형식대로 8개를 추가한다.
- 다 만든 뒤 8장을 직접 열어 확인한다. 알아보기 어렵거나 글자가 들어갔으면 다시 만든다.

## 건드리면 안 되는 것
- `fake-traveler/js/`, `*.html`, `*.css`, 다른 게임 폴더, 기존 그림 파일. 새 파일과 manifest 추가만 한다.
- 사용량 한도에 걸리면 멈추고 어디까지 했는지 한국어로 보고한다.
