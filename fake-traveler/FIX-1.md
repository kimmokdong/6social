# 가짜 여행자 — 선생님 결정 반영 (Codex 작업 지시)

검증 보고서(`VERIFY-REPORT.md`)의 제안 중 선생님이 승인한 5가지를 고친다. 다른 Codex 가 `trade-king/` 을 동시에 고치고 있으니 **`fake-traveler/` 밖은 건드리지 말 것.**

## 할 일
1. **사막 풀밭 문구**: "사막엔 풀밭이 없어요!"(사건 4 등, data.js·bank.js 의 같은 판정 문구 모두) → **"끝없는 풀밭은 스텝이에요!"** 처럼 스텝을 가리키는 말로. 판정(거짓/진짜) 자체는 바꾸지 말 것.
2. **기온 평균**: 툰드라 "여름에도 10℃ 아래", 빙설 "1년 내내 0℃ 아래" 같은 기후 특징·판정 문구에 **'평균'** 을 넣어 하루 기온으로 읽히지 않게(예: "가장 따뜻한 달 평균도 10℃ 아래", "1년 내내 평균 0℃ 아래"). 도감·사건 소개·라이어 여행단 '이번 여행지' 창에서 모두 자연스럽게 보이는지 확인. 짧게.
3. **고산의 비 칸**: `climates.highland.rain` 이 "공기가 희박해요"라 비(☔) 아이콘 아래 나온다 → 비 칸은 **"높이에 따라 달라요"**, 희박한 공기는 `look`(모습) 칸으로 옮기기(짧게).
4. **칭호 문구**: 라이어 여행단 칭호 설명 "3번 넘게" → **"3번 이상"**, "두 번 넘게" → **"두 번 이상"** (조건 숫자는 그대로).
5. **라운드 중 이어하기**: 라이어 여행단 대회 도중(라운드 소개·카드 내기·투표·결과 어디서든) 새로고침하면 지금은 처음부터 다시 시작된다 → **진행 중인 대회를 저장했다가 이어하기**.
   - `liar.js` 의 상태는 JSON 으로 저장 가능한 순수 객체이니 그대로 저장(새 키 `fake-traveler-v1-liar`, 기존 저장 키·기록은 건드리지 말 것).
   - 대회 고르기 화면에 '이어하기' 버튼(진행 중인 대회가 있을 때만). 대회가 끝나거나 그만두면 지움.
   - AI 차례 도중 새로고침해도 같은 카드를 두 번 내거나 건너뛰지 않게. 저장이 막혀도(localStorage 예외) 게임은 정상 진행.
   - `liar.js` 의 command·view 구조(멀티플레이 대비)와 결과 창 '나를 의심한 이유'(whyLine)는 유지.
   - 탐정 연습 사건 도중 이어하기도 쉬우면 같은 방식으로(어려우면 생략하고 보고).
