# 무역왕 4.1 작업 진행 기록

## 현재 상태

2026-10-22: `CODEX-V4.1-TASK.md`의 구현·검증·문서 갱신을 완료했다. 사용자가 동시 실행을 종료한 뒤 디스크의 `data.js`·`engine.js`·`game.js`·`rules.js`·`bots.js`를 처음부터 다시 검토했다.

## 완료한 변경

- 장인의 나라 자급 성능과 판매 프리미엄을 낮추고 식량·에너지 수입이 필요하도록 생산량을 조정했다.
- 바구니 필요량·생산량·시작 금고·위기 수입값·항구 수수료를 일관된 최종 수치로 통합했다.
- NPC 전략 A/B는 효율/균형 배치를 결정한다. 성격은 사건과 비축에 적용하며, 임시로 들어간 추가 산업 투자는 제거했다.
- 관세의 국내값과 결산 비용을 연결했다. 생산 전후에 관세를 바꿔도 최종 관세로 국내 물가 비용을 한 번만 계산한다. 금고 부족분은 바구니 구매량에서 반영한다.
- 보호 비용은 국내 물가·수입 관세·줄어든 수출 수입의 금액 환산이다. 기회비용에는 사건의 실제 생산 변화와 시장값을 반영했다.
- 위기 때 비축과 보호 산업 생산으로 피한 생활 수준 손실을 표시한다. 국내 생산 기여는 필요량까지로 제한했다.
- 시장 수량 `1 / 5 / 최대`, 최대 구매·판매, 창고 제한, 접근 가능한 이름과 최소 44px 영역을 유지·검증했다. 수량·수입국·관세 선택과 거래 후 키보드 초점을 유지한다.
- 4.1 버전만 이어하기로 받는다. 4.0 판은 안전하게 제외하고 새 판으로 시작하며, 저장 키 이름과 도감·해금 기록은 유지한다.
- `SPEC-v4.md` 본문·17장 결과를 갱신하고 18장에 전후 수치·새 봇 표·남은 제약을 기록했다.
- 임시 파일 `tests/tune.cjs`·`tests/calibrate.cjs`를 삭제했다.

- 수정한 자바스크립트 구문, UTF-8, 규칙서 생산·바구니 표와 실제 데이터의 일치, 방문 집계 스크립트 줄 유지를 확인했다.
