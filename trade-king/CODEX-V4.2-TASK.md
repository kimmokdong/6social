# Codex 작업 지시: 무역왕 4.2 — 튜토리얼과 "내 턴에 뭘 하지?" 안내

## 문제 (선생님 피드백)
> 화면에 나오는 여러 정보가 각각 무엇인지, 게임이 어떤 흐름으로 진행되는지 쉽게 파악되지 않는다. 튜토리얼로 쉽게 알려 주고, 내 턴에 해야 할 일과 턴이 이어지는 단계를 직관적으로 이해되게 해야 한다.

대상은 초등 6학년이고, 처음 하는 아이가 설명 없이도 1년째를 끝낼 수 있어야 한다.

## 현재 구조
- 규칙서는 `SPEC-v4.md`다.
- 엔진의 단계(`G.phase`)는 `event`(세계 소식 카드) → `assign`(일꾼 배치) → `trade`(무역) → `settlement`(결산 카드) → `policy`(3년째부터, 정책 카드) → 다음 해 순서로 진행된다. 마지막에는 `ending`이 온다.
- 1년째는 국경이 닫혀 무역이 없다.
- 화면은 `js/game.js`의 `render()`가 판 전체를 그린다. 구성은 위 순위 띠, 왼쪽 산업, 가운데 세계 지도, 오른쪽 국민 바구니, 아래 세계 시장, 맨 아래 바닥줄이다. 카드 창은 `openSheet`와 `fitSheet`로 띄운다.
- **엔진 규칙과 수치는 바꾸지 않는다**(`js/engine.js` 규칙과 `js/data.js` 수치 그대로). 바꾸는 것은 화면과 안내뿐이다. 필요하면 진행 저장(`progress`)에 튜토리얼 완료 표시 같은 필드만 추가한다.

## 만들 것

### 1. 단계 막대 (항상 보임)
- 위 띠(로고 아래나 순위 띠 옆)에 "① 세계 소식 → ② 일꾼 배치 → ③ 무역 → ④ 결산 → ⑤ 정책"을 넣는다.
  - 지금 단계는 색과 크기로 강조한다.
  - 끝난 단계는 ✓로 표시한다.
  - 1~2년째에는 ⑤ 정책을 자물쇠와 "3년째부터"로 보여 준다.
  - 1년째에는 ③ 무역을 "국경 닫힘"으로 흐리게 표시한다.
- 연도 표시는 "2년째 / 5년"처럼 5칸 점으로도 보여 준다.

### 2. "지금 할 일" 안내 카드 (바닥줄 왼쪽 설명 한 줄을 대체)
- 단계마다 실제 게임 상태로 계산한 체크리스트를 1~3줄 보여 준다. 예:
  - **일꾼 배치**:
    - "□ 일꾼 6명을 산업에 놓기 (남은 2명)"
    - "□ 바구니에서 비는 칸 확인하기"
    - 1년째에는 "혼자서 5칸을 다 채워 보세요"를 넣는다.
  - **무역**:
    - "□ 남는 물건 팔기: 기술제품 3상자"
    - "□ 모자란 칸 사기: 에너지·철"
    - "□ 거래 제안 1장 확인"
    - 끝난 줄은 ✓와 줄긋기로 바뀐다.
  - **결산·사건·정책**: 카드에서 고르라는 짧은 안내를 보여 준다.
- 오른쪽 큰 버튼 이름에 다음 단계를 넣는다. 예: "생산하고 ③ 무역으로 →", "④ 결산 보기 →".
  - 아직 할 일이 남았으면 버튼을 누를 때 한 번 확인한다. 예: "일꾼 2명이 쉬어요. 그래도 넘어갈까요?"
  - 이 확인은 화면 안 작은 확인 카드로 띄운다. `confirm()`은 쓰지 않는다.

### 3. 지금 쓰는 영역만 밝게 (스포트라이트)
- 일꾼 배치 때는 산업 패널과 바구니를 밝게 하고, 시장은 흐리게(불투명도 낮춤) 하면서 "③ 무역에서 열려요" 표시를 덮는다.
- 무역 때는 시장과 바구니를 밝게 하고, 산업 패널은 흐리게 한다.
- 흐린 영역도 읽을 수는 있어야 한다. 대비가 너무 낮지 않게 한다.

### 4. 첫 판 튜토리얼 (코치 마크)
- 처음 시작한 판(진행 저장에 완료 표시가 없을 때)의 1년째 시작에서 안내한다.
  - 안내 캐릭터는 기존 인물 그림 중 하나를 쓴다. 예: `shopkeeper` 또는 고른 나라의 인물.
  - 말풍선이 화면 영역을 하나씩 짚는다(그 영역에 테두리 강조, 나머지는 어둡게).
  - 순서는 다음과 같다. 각 말풍선은 2문장 이하, 쉬운 말로 쓴다.
    1. 단계 막대: "한 해는 이 순서로 흘러가요."
    2. 우리 나라 산업: "일꾼을 놓으면 물건이 생겨요. '1명당 n'이 클수록 잘 만드는 물건이에요."
    3. 국민 바구니: "국민에게 필요한 다섯 가지예요. 골고루 채울수록 생활 수준이 올라가요."
    4. 순위 띠: "다른 네 나라와 생활 수준으로 겨뤄요."
    5. 세계 지도: "이번 판에 함께하는 나라들이에요. 내년부터 배가 오가요."
    6. 세계 시장: "2년째부터 열려요. 남는 걸 팔고 모자란 걸 사요."
    7. 지금 할 일 카드: "막히면 여기를 보세요."
  - "다음", "건너뛰기" 버튼을 둔다. 키보드 Enter/Esc와 터치를 지원한다.
- **처음 나오는 순간 안내(그 판에서 처음일 때 한 번)**는 같은 말풍선 방식이다:
  - 2년째 무역 단계: 사기·팔기·수입 나라 고르기·수량 버튼을 알려 준다.
  - 첫 거래 제안: 거래 제안을 알려 준다.
  - 3년째: 관세와 정책을 알려 준다. "보호하면 국내 산업은 살지만 물건값이 올라요."
  - 4년째: FTA와 국제 회의를 알려 준다.
  - 의존도 70%가 처음 넘을 때: 빨간 줄과 ⚠의 뜻을 알려 준다.
- 각 안내는 진행 저장에 "본 안내" 목록으로 남긴다. 다음 판부터는 다시 띄우지 않는다.
- 도움말 버튼에서 "튜토리얼 다시 보기"를 할 수 있게 한다.
- 타이틀 또는 나라 고르기 화면에 "처음이에요(안내 켜기) / 안내 끄기" 선택을 둔다.

### 5. 정보 단계적 공개
- 1년째에는 바구니의 "의존 n%", 창고 줄, 시장의 수입 나라 선택·관세 줄을 숨기거나 간단히 줄인다. 숨겨도 패널 높이는 그대로다.
- 2년째에 의존도를 공개하고, 3년째에 관세를 공개한다.
- 처음 공개되는 해에는 그 요소에 "새로!" 배지를 단다.

### 6. 패널 `?` 설명
- 각 패널 제목 옆에 작은 `?` 버튼을 둔다(터치 44px). 누르면 2~3문장 설명 말풍선이 뜬다.
- 대상 패널: 우리 나라 산업, 세계 지도, 국민 바구니, 세계 시장, 순위, 금고.
- 숫자의 뜻도 설명한다: "1명당", "★ 기반", "의존 %", "생활 n".

## 지켜야 할 것
- **스크롤 금지**는 그대로다. 1366×768, 1280×800, 1024×768, 768×1024에서 페이지와 카드 모두 스크롤이 없어야 한다(390×844는 세로 스크롤 허용).
  - 패널 높이가 단계나 안내 때문에 출렁이지 않아야 한다.
  - 13px 미만 글자가 없어야 한다.
  - 말풍선이 화면 밖으로 나가지 않아야 한다.
  - 말풍선이 강조하는 영역 자체를 가리지 않아야 한다.
- 모든 문구는 한국어로 쓴다. 6학년이 읽기 쉬운 말로 쓰고, 한자어 용어는 처음 나올 때 풀어 쓴다.
- 새 그림은 만들지 않는다. 기존 인물 webp와 SVG 아이콘만 쓴다.
- `trade-king/` 밖은 건드리지 않는다. 단, 스크린샷은 기존처럼 `../output/trade-v4-verify/`에 저장한다.
- `index.html`의 project-visits 스크립트 줄은 그대로 둔다. CSS·JS 쿼리 버전(`?v=`)은 올린다.
- 배포하지 않고, 커밋도 하지 않는다.
