# 무역왕 사슬 균형 수정·검증 보고

## 현재 상태

`CHAINS-FIX.md`의 필수 여섯 검사를 모두 통과했습니다. 사슬 비교는 씨앗 0~299에서 해당 사건이 나오는 모든 판·모든 갈래 **1,494회, 실패 0회**입니다. 가장 작은 손해도 **25점**입니다. 점수는 기존 그대로 `행복 게이지 합 × 40 + 돈`이며, 숨은 벌점이나 씨앗 제외 조건을 추가하지 않았습니다.

균형 봇 무역왕은 **120/300판(40%)**, 반칙 봇은 **0/300판(0%)**입니다. 공정한 선택의 효과와 수치는 바꾸지 않았습니다. 결과는 지정된 검사 범위에 대한 확인이며, 모든 정수 씨앗·모든 사람의 전략에 대한 수학적 보장은 아닙니다.

실행: [무역왕](http://localhost:8790/trade-king/). 게임은 기존 순수 HTML/CSS/JS 구조를 유지합니다.

## 수정 범위와 규칙

- `js/engine.js`: `noContract`를 남은 기간의 최댓값으로 합칩니다. 새 계약만 거절하며 기존 계약은 배송을 계속합니다. 신뢰 1에서는 새 계약만 거절하고 단기 거래는 가능합니다. 신뢰 0이 되면 거래·새 계약을 거절하고 그 나라의 남은 계약을 끝냅니다. 이미 출발한 배송은 유지합니다. 계약 파기로 이웃의 신뢰가 0이 된 경우에도 해당 계약을 끝냅니다.
- 리콜은 `max(2, 그해 판 완성품 수) × recall`만큼 돈을 차감합니다. 옵션의 게이지 변화는 기존 공통 효과 처리로 적용되며 회귀 검사에 포함했습니다.
- 노드 자체의 `buy`·`trust`·`noContract`는 기존 `queue → effects`에서 사건이 나올 때 이미 적용하고 있었습니다. 이 처리를 재사용했고, 선택 전 적용·선택 후 중복 적용 방지를 검사했습니다.
- `js/game.js`: 계약 버튼을 거절 조건에 맞게 비활성화하고 옆에 `🔒 장기 계약 거절 n년`을 표시합니다. 신뢰만으로 거절하는 경우 기간 없이 표시합니다. 신뢰 0 나라의 성격 힌트 자리에 `거래를 끊었어요`를 표시합니다.
- `js/world.js`: 매년 얼음 항로가 닫히는 공급처를 제외한 곡물·석유 판매량이 그해 국민 필요량 이상인지 coverage로 확인합니다. 공급처의 존재만 검사하던 조건을 보완했습니다.
- `tests/bots.js`: 통행료를 낼 수 없는 판매처를 제외하고, 계약이 거절되면 단기 수입으로 관계를 쌓습니다. 부품 계약은 연 1대 조립분부터 확보하며, 필요량 증가는 다음 해를 기준으로 준비합니다. 운영자금이 140 미만이면 판매를 먼저 하고, 배 투자는 판매 뒤에 판단합니다.
- `tests/rules.js`, `tests/worlds.js`, `tests/walk.py`: 위 규칙과 공급량·거절 화면의 회귀 검사를 추가했습니다.
- `tests/data-before.txt`: 작업 시작 당시 기획자가 수정한 `data.js`를 새 보존 기준으로 복사했습니다. `tests/content.js`는 구조·글 변경, 사슬 밖 숫자 변경, 공정한 선택의 숫자 변경을 거절합니다.

저장 키 `trade-king-v1`, `trade-king-v1-game`은 유지했습니다. 다른 게임·상위 허브·`shared-art`에는 쓰기 작업을 하지 않았습니다.

**이 조정은 강합니다.** 관세 맞불 뒤에는 세계 수출 대금이 0이 되고, 외상 약속 위반 뒤에는 모든 나라의 신뢰가 0이 됩니다. 가격·기간은 화면과 실제 규칙에 드러나며, 숨은 점수 차감은 없습니다. 글 변경 제한 때문에 사건 글은 그대로입니다. 경제 현실을 그대로 재현하는 수치보다는 지정된 엄격한 사슬 비교를 만족시키는 게임 수치입니다.

## 보호 범위와 남은 한계

예전 `tests/protected-before.json`의 4,774개 파일과 현재 다른 게임·공용 그림을 비교한 결과는 변경 11개, 추가 340개입니다. 목록은 `tests/protected-result.json`에 남겼습니다. **이번 작업에서는 해당 경로를 수정하지 않았습니다.** 작업 시작 시 별도의 보호 해시 사본을 남기지 않았으므로, 이번 작업 기간 전체의 해시 동일성을 독립적으로 증명한 것으로 보고하지 않습니다. 기존 차이는 되돌리지 않았습니다.

세계 생성 조건이 강화되어 일부 씨앗의 세계가 달라졌습니다. 이전 세계를 저장한 판은 기존 이어하기의 세계 일치 검사에서 거절될 수 있습니다. 진행 기록 키는 유지했으며, 현재 세계에서의 저장·이어하기는 화면 검사로 확인했습니다.

실제 태블릿 하드웨어와 검사 범위 밖 씨앗은 추가 검증하지 않았습니다. 필수 검사에서 남은 실패는 없습니다.
