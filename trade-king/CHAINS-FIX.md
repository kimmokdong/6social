# 무역왕 — 사슬 균형 맞추기 (Codex 작업 지시)

## 배경
지난 보고(REPORT.md)대로 `tests/chains.js` 가 1,614회 중 818회 실패. 원인: 사슬 손해가 '한 번 내고 끝'이라, 아낀 돈을 일찍 굴린 판이 나중에 더 잘 풀리는 일이 많다(복리·문턱 효과).
기획자가 `js/data.js` 의 `nodes`(tariff2·tradeWar·recall·badRumor·promiseAngry)를 **오래 남는 손해**로 고쳐 두었다(이 내용이 새 기준). 질문하신 "후속 사건에 지연 효과 항목 추가"는 **허용**합니다.

## 할 일
1. 엔진에 새 효과·규칙 구현 (`js/engine.js`, 필요한 만큼 `game.js`):
   - 사슬 사건의 **사건 자체에 붙은 효과**(옵션이 아닌 노드 쪽 `buy`·`trust`·`noContract`)도 사건이 나올 때 적용.
   - `noContract: n` — n년 동안 어느 나라도 다온국과 **새 장기 계약**을 하지 않음(이미 있는 계약은 유지). 여러 번 오면 남은 해 중 큰 값.
   - 신뢰 규칙: 신뢰 0 → 그 나라는 거래·계약을 모두 거절하고 그 나라와의 계약은 끝남. 신뢰 1 → 새 장기 계약만 거절.
   - `recall: n` — 그해 판 완성품 수 × n 돈(최소 2대분). 옵션의 `gauge` 도 적용.
   - 화면: 장기 계약이 막혀 있으면 계약 버튼 옆에 자물쇠 + "장기 계약 거절 n년", 신뢰 0 나라 패널에 "거래를 끊었어요". 설명 문장은 늘리지 말 것.
2. `tests/content.js` 의 보존 기준을 지금의 data.js 로 새로 잡는다(기획자 수정분이 새 기준). 이후 Codex 는 **사슬 노드·사슬 시작 사건의 숫자만** 조정 가능.
3. `tests/chains.js` 를 다시 돌려 **모든 씨앗·모든 갈래에서 불공정 쪽 점수가 공정보다 낮게**. 안 되면 사슬 숫자(손해의 크기·기간)를 키우되, 공정한 길은 건드리지 말 것. 그래도 남는 씨앗이 있으면 숨기지 말고 씨앗별로 왜 그런지(해마다 돈·게이지·계약 흐름) 보고.
4. 균형 봇 점수가 0에 가까운 씨앗(예: 54)을 조사: 세계가 불공정하게 어려운지, 봇이 막히는지. 세계 문제면 world.js 의 coverage 조건을 고치고, 봇 문제면 봇을 고친다(공정한 길 성적을 일부러 낮추지 말 것).
5. `node tests/worlds.js`, `rules.js`, `content.js`, `sim.js`, `chains.js`, `python tests/walk.py` 모두 통과. sim 기준은 SPEC 7.2 그대로(균형 봇 무역왕 ≥35%, 반칙 봇 0~5%).
6. REPORT.md 를 갱신(바꾼 숫자와 이유, 결과).

## 건드리면 안 되는 것
다른 게임 폴더, `../shared-art/`, data.js 의 글·구조(사슬 숫자 조정만 허용), 저장 키. 사용량 한도에 걸리면 멈추고 어디까지 했는지 보고.
