# 7.9 체험 점검표 (한 장)

한 판(5년, 약 10분)을 직접 해 보고 칸에 ✓ 또는 한 줄 메모. 숫자 측정은 `../output/balance79/tuning-7.9c.md`에 있고, 여기는 **사람만 알 수 있는 것**만 본다.

**준비**: https://6social.pages.dev/trade-king/ · 처음엔 **큰 시장국** 또는 **대평원국**(첫 플레이 추천), 두 번째 판은 **다온국**(어려움).

## 1. 첫 1분
- [ ] 나라 고르기에서 "쉬움·보통·어려움"과 "첫 플레이 추천"이 눈에 들어온다
- [ ] 첫해에는 발전 회의가 없고, 바로 배를 보내는 데서 시작한다
- [ ] 첫 계약에서 "못 줘서 위약금"이 나와도 왜 그런지 이해된다 (상대 창고가 절반으로 시작)

## 2. 1년 안
- [ ] 지도 오른쪽 위 **작은 돌발** 카드가 한 달에 한 번쯤 — 너무 잦다 / 알맞다 / 드물다 (하나에 ○)
- [ ] 단추 붙은 돌발(상인 방문·급한 부탁)을 7일 안에 눌러 볼 수 있다
- [ ] 배가 쉬게 되면 **자동 멈춤**이 걸려서 놓치지 않는다 (⚙️에서 끌 수 있음)
- [ ] 물건 옆 ▲▼와 계약서 "최근 6달 중 싼 편"을 보고 한 번은 기다려 봤다

## 3. 발전 회의 (2~5년째 1월 1일)
- [ ] 카드 세 장이 서로 다른 콘셉트라 고민이 된다
- [ ] "🏭 1/3 → 2/3"처럼 모으기 진행이 보이고, 2장 보너스가 켜질 때 알아챘다
- [ ] 프리즘 카드가 나왔을 때 "와" 하는 느낌이 있다
- [ ] 우리 나라 특성 카드가 한 번은 나왔다
- [ ] 다시 뽑기(50억)를 써 볼 만하다고 느꼈다

## 4. 5년 흐름
- [ ] 해가 갈수록 점수가 오르는 느낌 (결과 책 막대: 1년 → 5년)
- [ ] 4·5년째에도 1등이 정해지지 않아 긴장된다
- [ ] 큰 사건이 4~5번, 너무 아프기만 하지 않다
- [ ] 결과 책 "우리 빌드" 줄이 내가 고른 길과 맞다

## 5. 다시 하고 싶은가
- [ ] 끝나고 바로 "다른 콘셉트로 한 번 더"가 하고 싶다
- [ ] 도감 🧩 증강체 칸에 새로 열린 카드가 반갑다
