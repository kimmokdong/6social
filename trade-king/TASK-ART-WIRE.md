# 무역왕 그림 — 2단계: 게임에 연결 (Codex 작업 지시)

1단계(`TASK-ART-IMAGES.md`)에서 만든 그림을 무역왕에 연결한다. 사슬 균형 작업(`CHAINS-FIX.md`)은 끝난 뒤다 — 그 결과(REPORT.md)를 먼저 읽고 망가뜨리지 말 것.

## 할 일
1. `shared-art/trade/slots.json` 의 좌표로 `trade-king/js/data.js` 의 `maps[*].slots` 숫자만 바꾼다(항로 연결·거리·규칙은 그대로). 지도 뒤집기는 CSS 변환으로(그림에 글자가 없으니 그대로 뒤집어도 됨).
2. 지도: 그림 지도(`map_{틀}.webp`) 위에 항구 그림(만난 나라만 `port_{id}`, 다온국 `port_home`, 안개 속은 `fog_*`), 그 위에 항구 핀·이름표·항로 점선·폭풍·해협·얼음 표시는 지금처럼 SVG. 안개는 처음 만날 때 걷히는 애니메이션. 배는 `ship.webp` 가 항로를 따라 이동(지금 SVG 배 자리에).
3. 나라 패널·거래 창·사건 카드의 인물 → `shared-art/people/{나라id}.webp` (`js/paint.js`). 타이틀·엔딩 신문 → `trade/title.webp`, `trade/end_*.webp`.
4. 그림을 못 불러오면 **지금 SVG 그대로**. 글씨 크기·버튼·규칙은 그대로.

## 완료 조건
- 지도 4종 × 뒤집기 4가지를 모두 찍어(`trade-king/tests/shots/art-*.png`) 핀이 섬 위에 있는지, 겹침·잘림 없는지 직접 확인.
- 1366×768·768×1024·390×844 에서 타이틀→플레이(탐험·거래·조립·사건)→엔딩→도감, 콘솔 오류 0.
- 그림 이름을 일부러 틀리게 해서 SVG 대체 확인. `node tests/*.js` 와 `python tests/walk.py` 모두 통과(좌표만 바뀌었으니 규칙 결과는 같아야 함).
