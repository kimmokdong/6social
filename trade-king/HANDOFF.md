## 4. 꼭 알아야 할 구현 메모
- **디버그**: `?debug=1`이면 `window.TK = {G, E, T, render, cargo, coach}`. 일반 모드에서는 숨는다.
- **저장 키**: `trade-king-v4-game`, `trade-king-v4-progress`. 저장 버전은 `T.version === 5`로 확인하고, 4.x 저장은 이어하기에서 뺀다.
- **끌어다 놓기**: 끄는 것은 `[data-drag]`(worker / ship / box), 놓는 곳은 `[data-drop]`. 6px 움직이면 끌기가 시작되고, 끈 뒤 생기는 클릭은 막는다. 누르기만으로도 같은 일을 할 수 있다.
- **부두 교환대**: `cargo = {to, give, get}`. 지도 자리에 대신 그려진다. 짐 종류마다 상자 6개까지 싣는다. Esc는 '배 돌리기'다.
- **연출(5.2)**:
  - `next()`가 `E.endPhase` 뒤에 `holdSheet = true`로 시트를 미뤄 두고 `playFx(steps, done)`를 돈다.
  - 단계별로 이렇게 움직인다.
    - `produceFx`: 공장 → 바구니로 상자가 날아간다.
    - `voyageFx`: 우리 배가 항구 → 섬 → 항구로 오가고, 다른 나라 배는 `G.npcRoutes`를 따라간다.
    - `scoreFx`: 생활 점수가 순위표로 날아간다.
  - Web Animations API를 쓴다. 화면을 누르면 건너뛴다.
  - `prefers-reduced-motion`이면 연출을 생략한다. 테스트는 이 설정으로 돌기 때문에 **연출 자체는 자동 검사 밖**이고, 브라우저에서 눈으로 확인했다.
- **그림 경로**: `const ART = new URL('../shared-art/trade/', location.href).href`처럼 절대 주소로 쓴다. CSS 변수 속 상대 `url()`은 `css/` 기준으로 풀려서 깨진다.
- **그림 재사용**: 새 그림은 없다. 기존 `shared-art/trade/`의 `port_<초상id>.webp`, `ship.webp`, `title.webp`, `end_*.webp`만 쓴다. 미리 불러오기 목록은 `shared/game-assets.js`의 `"trade-king"`이다.
- **엔진 수정 사항(5.x)**:
  - 사건 계획을 바꿀 때 같은 종류끼리만 바꾼다. 그래서 위기는 항상 2번이다.
  - 만들기 단계의 섬 표시는 그해 그 나라 생산량을 넣은 예상값이다.
