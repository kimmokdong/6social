**거리 그림의 원근과 화면 품질**

스크린샷을 직접 열어 타이틀·튜토리얼·아침·거리·비·푸드트럭·저녁·사건·선택 결과·엔딩·잠긴 도감·열린 도감·설정·대체 그림을 확인했다. 대표 화면은 다섯 해상도에 걸쳐 확인했으며, 저장된 모든 PNG를 한 장씩 열어 본 것은 아니다.

- 거리 그림의 표시 비율은 16:9이며 원본 비율과 맞는다. 걷는 아이와 소품은 비율을 유지한다.
- 두 가게 앞은 같은 깊이로 처리되어 아이 배율이 각각 1.15다. 출발 1.22, 푸드트럭·품절 위치 1.20, 앞쪽으로 나오는 경로 1.30이다.
- 다섯 크기에서 알바 성인 그림의 표시 상자가 아이 그림 상자보다 컸다. 예: 1366×768에서 성인 약 188px, 가게 앞 아이 약 130px, 앞쪽 아이 약 147px. 390×844에서는 각각 약 58px, 40px, 45px. 이는 DOM 표시 상자의 수치이며 그림 내부의 투명 여백을 제거한 신체 실측은 아니다.
- 배경 속 사장님과 추가 알바, 가게 앞 아이의 상대 크기는 직접 본 화면에서 납득 가능한 범위였다. 아이가 멀리 있는 학교 학생보다 크고, 가까운 인도로 나올 때 조금 커졌다.
- 가로 스크롤, 주요 글자 잘림·겹침, 접근할 수 없는 주요 버튼을 발견하지 못했다. 휴대폰의 아침·정산·도감·엔딩은 세로로 스크롤한다.
- 검사 대상 본문·보조 문구는 18px 이상, 버튼 자체의 글꼴은 20px 이상, 일반 터치 버튼은 44×44px 이상이었다. 디버그 도구의 작은 글씨·버튼은 학생 화면 검사에서 제외했다.

**검사 환경과 한계**

- 기존 `http://localhost:8790/`에서 검사를 시작했다. 공용 서버가 검사 중 `paint.js` 요청에 `ERR_CONNECTION_REFUSED`를 반환했고 `Paint is not defined`로 초기화가 중단됐다. 다른 작업의 서버는 수정·종료하지 않았다. 동일 파일을 읽는 전용 `127.0.0.1:8791`에서 전체 UI와 추가 검사를 다시 끝냈고 오류 0건을 확인했다. 엣지 15항목은 8790에서 통과했다.
- `python`이 PATH에 없어 기존 Codex Python을 직접 실행했다. 공용 Playwright 패키지 읽기 제한은 자동 승인된 실행으로 해결했다. 별도 패키지를 설치하지 않았다.
- `chains.js`는 실패 판단을 출력으로 알리는 스크립트다. 종료 코드만 보지 않고 마지막 ‘모든 갈래가 거절보다 손해’와 각 갈래 수치를 확인했다. 실제 비교 표본은 담합 갈래당 60판, 광고 43판, 원산지 42판, 머리카락 3판이다. 특히 머리카락은 위생 투자로 사건이 생략되는 판이 많아 표본이 작다. 모든 씨앗·전략에 대한 수학적 보장은 아니다.
- Chrome의 실제 브라우저를 사용했지만 태블릿·크롬북 실기기, 물리 키보드·터치, 스피커로 들리는 음량은 확인하지 않았다. 파일 실행 검사는 Chrome 기준이다.
- `game.js`, `style.css`, `data.js`, `engine.js`, `tycoon-art.js`의 SHA-256은 재검사 전후 같았다. 저장 키도 그대로다. 동시 작업 중인 폴더 전체의 Git 변경 목록은 저장소가 아니므로 확보하지 못했고, 다른 작업 결과를 덮어쓰지 않았다.
