# 플레이 결과 화면 설계 (확정 내용 누적)

근거 성취기준: [6사11-01] 시장경제에서 가계와 기업의 역할을 이해하고 근로자의 권리와 기업의 자유 및 사회적 책임을 탐색한다.
- 볼 수 있는 요소: 기업의 역할, 가계의 역할(선택), 기업의 자유, 기업의 사회적 책임
- 볼 수 없는 요소: 근로자의 권리(알바 고용 카드뿐이라 범위에서 뺌)

화면 순서: 엔딩 신문 → 사장님 인터뷰 → 사장님 유형 → 이번 판 사회 실력 → 내 플레이 속 사회 공부

## 1. 인터뷰 문항 (확정 2026-11-12)

- 한 판 4문항. 칸 순서: ① 역할 ② 가계 ③ 자유 ④ 책임. 칸마다 위에서부터 첫 번째로 맞는 문항 하나.
- 파산 등으로 맞는 문항이 없으면 그 칸은 건너뜀(2문항까지 허용).
- ✅ = "까닭을 알아봄". 보기 순서는 씨앗으로 고정 섞기. 누른 직후 맞고 틀림 표시 없음.

### ① 기업의 역할
- B1 재료가 모자라 10명 넘게 돌아간 날(준비 재료 < 판매 한도) → 가장 많이 돌아간 날
  "N일째 [소식]에 재료가 모자라 A명이 그냥 돌아갔어요. 왜 그랬을까요?"
  ✅사려는 손님이 많을 것을 덜 헤아리고 재료를 적게 준비했어요 / 그냥 운이 나빴어요 / 손님들이 너무 많이 먹어서요
- B2 15그릇 넘게 남아 버린 날 → 가장 많이 남은 날
  "N일째 [소식]에 A그릇이 남아서 버렸어요. 왜 그랬을까요?"
  ✅사려는 손님 수보다 재료를 많이 준비했어요 / 그냥 운이 나빴어요 / 손님들이 배가 불러서요
- B3 값을 올렸더니 판 그릇이 줄어든 날(전날보다 지나간 아이가 많은 날 제외)
  "N일째에 값을 X원에서 Y원으로 올렸더니 판 그릇이 A그릇에서 B그릇으로 줄었어요. 왜 그랬을까요?"
  ✅값이 오르면 용돈 안에서 사려는 사람이 줄어요 / 그날 날씨가 나빠서요 / 손님들이 떡볶이에 질려서요
- B4 투자한 날 → 첫 투자
  "N일째에 [투자]에 A원을 썼어요. 그날 돈이 줄었는데도 투자한 까닭은 무엇인가요?"
  ✅돈을 먼저 써서 손님이나 판매를 늘리려고요 / 돈이 남아서 그냥 썼어요 / 투자하면 그날 바로 돈이 생겨서요
- B5(기본) 손님 수가 바뀌는 날(없으면 첫날)
  "N일째 [소식]에 재료를 A그릇 준비했어요. 재료 수를 정할 때 무엇을 살펴야 할까요?"
  ✅오늘 소식을 보고 사려는 손님 수를 미리 헤아려야 해요 / 어제와 똑같이 하면 돼요 / 재료는 많을수록 좋아요

### ② 가계의 선택 이해하기
- G1 왕떡볶이 손님이 우리보다 많았던 날 → 차이가 가장 큰 날
  "N일째에 A명은 왕떡볶이로, B명은 우리 가게로 왔어요. 손님들이 왕떡볶이를 더 많이 고른 까닭은 무엇일까요?"
  ✅용돈 안에서 값·맛·평판을 따져 보니 그날은 왕떡볶이가 더 낫다고 느꼈어요 / 그냥 운이 나빴어요 / 왕떡볶이 간판이 더 크고 멋져서요
- G2(기본) 우리 손님이 가장 많았던 날
  "N일째에 A명이나 우리 가게에 왔어요. 손님들이 우리 가게를 고른 까닭은 무엇일까요?"
  ✅값에 비해 맛과 평판이 좋아서 더 만족스러울 거라 여겼어요 / 손님이 많은 날이라 아무 데나 들어갔어요 / 제가 운이 좋았어요

### ③ 기업의 자유
- F1 담합으로 값이 묶인 날이 있음
  "N일 동안 값이 4,000원에 묶여 있었어요. 그동안 오늘 소식이나 손님 수에 맞춰 값을 바꿀 수 있었나요?"
  ✅아니요, 약속 때문에 값을 스스로 정할 수 없었어요 / 네, 언제든 바꿀 수 있었어요 / 값은 원래 나라에서 정해 줘요
- F2 값을 한 번 이상 바꿈
  "이번 판에 값을 N번 바꿨어요. 가게가 값을 스스로 바꿀 수 있는 까닭은 무엇일까요?"
  ✅시장경제에서는 기업이 값을 스스로 정할 자유가 있어요 / 왕떡볶이가 허락해 줘서요 / 나라에서 정해 준 대로 한 거예요
- F3(기본) 값을 한 번도 바꾸지 않음
  "N일 내내 값을 X원으로 두었어요. 값을 바꿀 수도 있었을까요?"
  ✅네, 가게는 상황에 맞게 값을 스스로 정할 수 있어요 / 아니요, 처음 정한 값은 못 바꿔요 / 왕떡볶이와 값이 같아야 해요

### ④ 기업의 사회적 책임 탐색하기 (받아들인 불공정 제안이 여럿이면 가장 이른 것)
- S1 담합 수락 + 푸드트럭 등장
  "N일째에 왕떡볶이와 값을 4,000원으로 맞췄죠. M일째에 푸드트럭이 나타난 까닭은 무엇이라고 생각하세요?"
  ✅두 가게가 다 비싸서 싼 가게가 들어올 틈이 생겼어요 / 그냥 운이 나빴어요 / 우리 떡볶이가 맛이 없어서요
- S2 담합 수락, 푸드트럭 전에 끝남
  "N일째에 왕떡볶이와 값을 4,000원으로 맞췄죠. 손님들에게는 어떤 일이 생겼을까요?"
  ✅고를 가게가 없어서 비싼 값을 내야 했어요 / 손님에게는 아무 상관 없었어요 / 두 가게 값이 같아서 고르기 편했어요
- S3 과장 광고 수락
  "N일째에 '세계 1등 떡볶이!' 전단지를 뿌렸죠. 다음 날 손님이 실망한 까닭은 무엇일까요?"
  ✅사실이 아닌 광고라 손님이 속았다고 느꼈어요 / 손님이 너무 까다로워서요 / 그냥 운이 나빴어요
- S4 원산지 속이기 수락
  "N일째에 외국산 떡을 국산이라고 써 붙였죠. 할머니가 '국산 맞지?' 하고 물어본 까닭은 무엇일까요?"
  ✅손님은 무엇을 먹는지 제대로 알고 고를 권리가 있어서요 / 할머니가 그냥 궁금해서요 / 외국산 떡은 원래 몸에 나빠서요
- S5 머리카락 불만 모른 척
  "N일째에 머리카락이 나왔다는 말을 못 들은 척했죠. 다음 날 그 손님이 다시 찾아온 까닭은 무엇일까요?"
  ✅손님은 안전한 음식을 먹을 권리가 있어서 사과를 받아야 해요 / 떡볶이를 또 먹고 싶어서요 / 그냥 트집을 잡으려고요
- S6 아동센터 기부
  "N일째에 아동센터에 떡볶이를 나눠 주느라 3만 원을 썼어요. 가게가 돈을 쓰면서도 이런 일을 하는 까닭은 무엇일까요?"
  ✅가게도 이웃과 함께 사는 사회의 한 사람이라서요 / 손해니까 사실은 안 하는 게 맞아요 / 별(평판)을 올리려고만 하는 거예요
- S7 머리카락 불만에 사과·환불
  "N일째에 머리카락 불만에 사과하고 3,000원을 돌려줬어요. 돈까지 돌려준 까닭은 무엇일까요?"
  ✅손님은 안전한 음식을 먹을 권리가 있고, 가게는 잘못을 책임져야 해서요 / 사실은 안 돌려줘도 됐어요 / 그 손님이 울까 봐서요
- S8 담합 거절(가격 전쟁)
  "N일째에 회장님의 가격 약속을 거절했죠. 그 뒤 가격 전쟁 동안 손님들에게는 어떤 일이 있었을까요?"
  ✅가게끼리 경쟁해서 손님은 더 싸게 사 먹었어요 / 손님에게는 아무 상관 없었어요 / 두 가게가 싸워서 손님이 불편했어요

## 2. 사장님 유형 (확정 2026-11-12)

축 3개(막대, 가운데 기준 나눔) → 8유형. 공정(사회적 책임)은 축에 넣지 않음.
- 재료: 재료를 늘 비슷하게 ↔ 날마다 바꿔 보기 — 전날보다 10그릇 넘게 바꾼 날 수, 3일 이상이면 오른쪽
- 가격: 값을 낮춰 많이 팔기 ↔ 값을 높여 제값 받기 — (내 평균 값 − 왕떡볶이 평균 값), 0원 이상이면 오른쪽, 막대 −1,500~+1,500
- 돈 쓰기: 돈을 아껴 모으기 ↔ 돈을 써서 가게 키우기 — 투자 횟수, 2번 이상이면 오른쪽, 막대 0~4

| 재료·가격·돈 | 이름 | 설명 |
|---|---|---|
| 비슷·낮게·모으기 | 차곡차곡 알뜰 사장님 | 재료를 늘 비슷하게 준비하고, 값은 낮게 두고, 번 돈은 아껴 모았어요. 꾸준히 같은 방식으로 가게를 지켰어요. |
| 비슷·낮게·키우기 | 문 활짝 동네 사장님 | 값을 낮게 두고 가게를 키우는 데 돈을 썼어요. 많은 손님을 맞이할 준비를 한 판이었어요. |
| 비슷·높게·모으기 | 한결같은 장인 사장님 | 정한 값과 재료를 크게 바꾸지 않고 제값을 받았어요. 내 방식을 믿고 꾸준히 밀고 나갔어요. |
| 비슷·높게·키우기 | 정성 가득 맛집 사장님 | 가게에 돈을 들이고 그만큼 제값을 받았어요. 맛과 가게를 키워 손님을 맞으려 했어요. |
| 바꿈·낮게·모으기 | 날씨 읽는 알뜰 사장님 | 그날그날 재료 수를 바꾸며 값은 낮게 두었어요. 돈은 아껴 모으는 쪽을 골랐어요. |
| 바꿈·낮게·키우기 | 발 빠른 도전 사장님 | 재료도 바꾸고 투자도 해 보며 이것저것 시도했어요. 값을 낮춰 손님을 많이 모으려 했어요. |
| 바꿈·높게·모으기 | 꼼꼼한 계산 사장님 | 날마다 재료 수를 따져 바꾸고 제값을 받았어요. 돈을 쓰는 데는 신중했어요. |
| 바꿈·높게·키우기 | 척척 기획 사장님 | 재료·값·투자를 모두 적극적으로 정했어요. 가게를 키우며 제값을 받는 계획을 세웠어요. |

공통 문장: "이 유형은 이번 판 10일 동안의 모습이에요. 다음 판에 다르게 해 보면 다른 사장님이 될 수 있어요."
같은 번호 지난 판이 있으면 "지난 판: ○○ 사장님".

## 3. 별 기준 (확정 2026-11-12)

공통: 해 봄(0~2) + 까닭을 알아봄(✅ 1) → 0~1 ★ / 2 ★★ / 3 ★★★. 최종 돈·평판은 쓰지 않음. 해 봄·까닭 두 칸을 따로 표시.

1. 기업의 역할 — 셋 다 통과 2, 1~2개 1, 0개 0
   - 수요 읽기: 아이 수 배율이 전날과 0.2 넘게 바뀐 날에 재료를 맞는 쪽으로 바꾼 비율 ≥60%
   - 가격 정하기: 신호(전날 왕떡볶이 손님이 더 많고 내 값이 더 비쌈 / 왕떡볶이 값이 바뀜) 있던 날 값을 바꾼 비율 ≥50% (묶인 날 제외)
   - 투자: 오래가는 투자(치즈·순대·의자·알바·위생)를 5일째 안에 1번 이상
   - 한마디: 통과한 것 중 첫째(수요→가격→투자), 없으면 수요 읽기 결과
2. 가계의 선택 — ✅ 2점, 해 봄 0~1(값·맛을 바꾼 날 다음 날 재료를 그날 손님 수(판매+못 산 손님) ±5 쪽으로 고친 비율 ≥50%)
   - ✅+해봄 ★★★ / 하나 ★★ / 없음 ★
3. 기업의 자유 — 스스로 바꾼 횟수 = 값 바꾼 횟수 + 투자 횟수(묶인 날 제외)
   - 2점: 자유로운 날의 절반 이상이고 4번 이상 / 1점: 2번 이상 / 0점
   - 묶인 날이 있으면 "4일째~6일째(3일)는 약속 때문에 값을 스스로 정할 수 없었던 날이에요." (별 반영 없음)
4. 사회적 책임 — 같은 번호 모든 판 합산, 갈래 10개(사건 5 × 받아들임/거절)
   - 2점: 양쪽 다 겪은 사건 ≥2 / 1점: 양쪽 1개 또는 확인 갈래 ≥4 / 0점
   - 까닭: 이번 판 ④ 문항 ✅
   - 사건별 표(양쪽 확인 여부 + 이어진 일), 위생 점검 한 줄
- 지난 판 비교: 같은 번호 바로 앞 판과 별이 달라진 항목에 ▲/▼
- 다음 판 도전: 별 가장 낮은 항목(같으면 역할→가계→자유→책임). 책임이면 "'○○'에서 아직 골라 보지 않은 쪽을 고르면 무슨 일이 이어질까요?"
- 화면 안내: "이 별은 이번 판에서 해 본 것과 알아본 것을 보여 줘요. 다시 하면 달라져요." (생활기록부 언급 없음)
- 기준값은 시뮬레이션으로 별 분포를 본 뒤 조정 가능(바꾸기 전 사용자 확인)

## 4. 개념 카드 (확정 2026-11-12)

- 카드 3장 = 이번 판 ①역할 ②가계 ④책임 인터뷰 문항의 상황. ③자유 답은 별 화면 자유 한마디 아래 한 줄.
- 틀: 한 일(N일째, 숫자) → 그 뒤 일어난 일(기록·trail) → 개념(굵게) → 마지막 문장
  - ✅: "인터뷰에서 '{보기}'라고 답했죠. 바로 그 까닭이에요!"
  - 그 밖: "인터뷰에서 '{보기}'라고 답했죠. 그렇게 볼 수도 있어요. 그런데 실제 까닭은 이거예요. {실제 까닭}"
- 문항별 문장은 대화에서 확정한 표 그대로(B1~B5, G1~G2, S1~S8, F1~F3 한 줄). 꾸짖는 말 없음.
- 도감 chains.lesson 은 카드에 쓰지 않음(갈래를 모두 찾을 때만 열리는 지금 설계 유지).

## 5. 교사용 화면 → 범위 축소 (2026-11-12, 확인 대기)

- 이번에는 학생이 자기 화면에서 결과를 보는 단계까지만. 전송·수집은 나중에 DB·서버 개념을 가르칠 때 확장 가능하다고 안내.
- 학생 번호 입력, 기록 내보내기, 실제 교사용 페이지는 만들지 않음.
- 지난 판 비교와 사회적 책임 누적은 이 기기에 쌓인 판 기록 기준(설정 '기록 모두 지우기'로 초기화).
- 연수 자료용 예시: 가상 학생 6명 × 2~3판을 엔진으로 실제 돌려 만든 정적 예시 페이지(docs/teacher-example.html, 게임에서 링크하지 않음)를 캡처해 PNG(반 전체 / 학생 상세)로 저장.
- 예시 화면 내용: 성취기준 상자, 유형 분포, 항목별 별 분포, 사건별 선택 통계, 인터뷰 답 분포, 학생 상세(유형·별·요소별 근거 2칸·개념 카드·판마다 변화).

## 4-1. 개념 카드 문장 (확정 원문)

틀: 한 일 → 그 뒤 일어난 일 → 개념(굵게 **…**) → 마지막 문장(✅ / 다르게 고름: 아래 '실제 까닭')

### ① 역할
- B1: "N일째 [소식], 재료를 A그릇 준비했어요." → "B명이 못 사고 돌아가서 별이 깎였어요." → "사려는 사람의 양을 **수요**라고 해요. 수요를 헤아려 만들 양을 정하는 것이 **기업**이 하는 일이에요."
  실제 까닭: "그날은 지나가는 아이가 많은 날이었어요. 손님이 늘 것을 미리 헤아려 재료를 늘렸다면 더 팔 수 있었어요."
- B2: "N일째 [소식], 재료를 A그릇 준비했어요." → "B그릇만 팔리고 C그릇을 버려 재료비 D원을 잃었어요." → "사려는 사람의 양을 **수요**라고 해요. 수요보다 많이 만들면 남아서 손해예요."
  실제 까닭: "그날 사려는 손님은 B명쯤이었어요. 소식을 보고 재료를 줄였다면 버리는 돈이 적었을 거예요."
- B3: "N일째에 값을 X원에서 Y원으로 올렸어요." → "판 그릇이 A그릇에서 B그릇으로 줄었어요." → "값이 오르면 사려는 사람이 줄어요. 기업은 **가격**과 손님 수를 함께 따져 값을 정해요."
  실제 까닭: "손님은 정해진 용돈 안에서 사요. 값이 오르면 덜 사거나 더 싼 가게로 가요."
- B4: "N일째에 [투자]에 A원을 썼어요." → "그 뒤 [맛 3.0 → 4.0 / 판매 한도 40 → 55그릇 / 평판 / 지나가는 아이 등 실제 바뀐 것], 하루 평균 판 그릇이 B그릇에서 C그릇이 됐어요." → "앞으로 더 벌려고 지금 돈을 쓰는 것을 **투자**라고 해요."
  실제 까닭: "투자는 그날 바로 돈이 생기는 게 아니라, 가게를 키워 다음 날부터 더 팔기 위한 거예요."
- B5: "N일째 [소식]에 재료를 A그릇 준비했어요." → "지나간 아이 B명 가운데 C명이 우리 가게에 왔어요." → "사려는 사람의 양을 **수요**라고 해요. 기업은 수요를 미리 헤아려 만들 양을 정해요."
  실제 까닭: "날씨나 행사에 따라 지나가는 아이 수가 달라져요. 오늘 소식을 보고 재료를 정하면 덜 남기고 덜 모자라요."

### ② 가계
- G1: "N일째에 값 X원, 맛 Y로 장사했어요." → "A명이 왕떡볶이로 갔어요. 가장 많은 까닭은 '{까닭 1위}'(B명)였어요." → "손님 같은 **가계**는 정해진 돈 안에서 값·맛·평판을 따져 가장 만족스러운 곳을 골라요. 이것을 **합리적 선택**이라고 해요."
  실제 까닭: "손님은 운이 아니라 까닭이 있어서 골라요. 그날 B명은 '{까닭 1위}' 왕떡볶이를 골랐어요."
- G2: "N일째에 값 X원, 맛 Y로 장사했어요." → "A명이 우리 가게에 왔어요. 가장 많은 까닭은 '{까닭 1위}'(B명)였어요." → (G1과 같은 개념 문장)
  실제 까닭: "손님은 아무 데나 가지 않아요. 그날 B명은 '{까닭 1위}' 우리 가게를 골랐어요."
  {까닭 1위}는 engine choiceSummary 의 why 문구(맛이 더 좋아서, X원 더 싸서, 평판이 더 좋아서, 왕떡볶이 단골이라서, 친구 따라, 두 가게가 같은 값이라서)를 씀.

### ④ 책임 (꾸짖는 말 없음)
- S1: "N일째에 왕떡볶이와 값을 4,000원으로 맞췄어요." → "{trail 이어진 일: 예) 5일째 푸드트럭 등장 → 6일째 신고, 과징금 4만 원}" → "가게끼리 몰래 값을 함께 정하는 것을 **담합**이라고 해요. 손님이 고를 기회를 빼앗고 **경쟁**을 막아서 법으로 금지해요."
  실제 까닭: "두 가게가 다 비싸면 싸게 팔 가게가 들어올 틈이 생겨요. 푸드트럭은 그 틈을 보고 온 거예요."
- S2: (S1과 같은 한 일) → "담합하는 동안 손님들은 다른 데가 없어서 비싸도 사 먹었어요." → (S1 개념)
  실제 까닭: "두 가게 값이 같으면 손님은 더 싼 곳을 고를 수 없어요. 그래서 비싼 값을 그대로 내야 해요."
- S3: "N일째에 '세계 1등 떡볶이!' 전단지를 뿌렸어요." → "그날 손님이 늘었지만 다음 날 '광고랑 다르잖아요!' {이어진 일}" → "사실과 다르게 부풀린 광고를 **과장 광고**라고 해요. 손님을 속여서 법으로 막아요."
  실제 까닭: "손님은 광고를 믿고 왔다가 실제와 달라서 속았다고 느낀 거예요."
- S4: "N일째에 외국산 떡을 국산이라고 써 붙였어요." → "3일 동안 재료비가 500원이 됐고, M일째 할머니가 '국산 맞지?' 물었어요. {이어진 일}" → "재료가 어디서 났는지 바르게 알리는 것을 **원산지 표시**라고 해요. 손님이 알고 고를 **소비자의 권리**를 지키려고 속이는 것을 막아요."
  실제 까닭: "외국산 떡이 나쁜 게 아니에요. 문제는 속인 거예요. 손님은 무엇을 먹는지 알고 고를 권리가 있어요."
- S5: "N일째에 머리카락이 나왔다는 말을 못 들은 척했어요." → "다음 날 그 손님이 다시 왔어요. {이어진 일}" → "손님이 안전한 음식을 먹고 피해를 보상받을 수 있는 것을 **소비자의 권리**라고 해요. 문제를 책임지는 것이 기업의 **사회적 책임**이에요."
  실제 까닭: "손님은 트집을 잡은 게 아니에요. 안전한 음식을 먹을 권리가 있어서 사과를 받으러 온 거예요."
- S6: "N일째에 아동센터에 떡볶이를 나눠 주느라 3만 원을 썼어요." → "그날 별이 0.8 올랐어요." → "이윤만이 아니라 이웃과 사회를 생각하는 것을 기업의 **사회적 책임**이라고 해요."
  실제 까닭: "별이 오른 것도 맞지만 그게 다가 아니에요. 가게도 마을 사람들과 함께 살기 때문에 이웃을 돕는 거예요."
- S7: "N일째에 머리카락 불만에 사과하고 3,000원을 돌려줬어요." → "그날 별이 0.3 올랐고, 더 이어진 일은 없었어요." → "손님은 피해를 보상받을 **소비자의 권리**가 있어요. 잘못을 바로 책임지는 것이 기업의 **사회적 책임**이에요."
  실제 까닭: "돈을 돌려준 건 손님이 울까 봐가 아니라, 손님에게 피해를 보상받을 권리가 있기 때문이에요."
- S8: "N일째에 회장님의 가격 약속을 거절했어요." → "왕떡볶이가 500원을 내려 가격 전쟁이 벌어졌다가 M일째에 끝났어요." → "가게끼리 손님을 두고 겨루는 것을 **경쟁**이라고 해요. 경쟁하는 동안 손님은 더 싸게 살 수 있어요."
  실제 까닭: "가격 전쟁은 두 가게에는 힘들었지만, 손님은 그동안 더 싸게 사 먹었어요."

### ③ 자유 한 줄(별 화면, 다르게 골랐을 때 / ✅면 "인터뷰에서도 까닭을 짚었어요.")
- F1: "담합 약속을 하면 값을 스스로 정할 수 없게 돼요. 원래 가게는 상황에 맞게 값을 정할 **기업의 자유**가 있어요."
- F2: "값은 왕떡볶이나 나라가 정해 주지 않아요. 시장경제에서는 가게가 스스로 정해요. 이것이 **기업의 자유**예요."
- F3: "값은 한 번 정하면 끝이 아니에요. 가게는 날마다 상황에 맞게 값을 바꿀 수 있어요. 이것이 **기업의 자유**예요."

## 별 한마디 문장(확정 예시 → 틀)
- 역할: "날씨나 행사가 달라진 날 {n}번 중 {k}번, 재료를 알맞게 바꿨어요." / "왕떡볶이 값이 바뀌거나 손님을 더 많이 데려간 날 {n}번 중 {k}번, 내 값을 다시 정했어요." / "{d}일째에 {투자}에 투자해 가게를 키웠어요." / 미통과: "날씨나 행사가 달라진 날 {n}번 중 {k}번만 재료를 바꿨어요."
- 가계: "값이나 맛을 바꾼 날 {n}번 중 {k}번, 다음 날 손님 수에 맞춰 재료를 고쳤어요." / ✅: "인터뷰에서 손님이 값·맛·평판을 따져 가게를 고른다는 것을 짚었어요." / 바꾼 날 없음: "값이나 맛을 바꿔 본 날이 없어서 손님 반응을 살펴볼 기회가 적었어요."
- 자유: "스스로 정할 수 있던 {f}일 동안 값을 {p}번 바꾸고 투자를 {u}번 했어요." + 묶인 날: "{a}일째~{b}일째({n}일)는 약속 때문에 값을 스스로 정할 수 없었던 날이에요."
- 책임: "사건 5개 중 {n}개에서 받아들였을 때와 거절했을 때를 모두 확인했어요." (0개면 "지금까지 사건 갈래를 {k}개 확인했어요.")
- 다음 판 도전: 역할 "날씨나 행사 소식을 보고 재료 수를 바꿔 보세요."(미통과 항목에 따라 가격: "왕떡볶이 값이나 어제 손님 수를 보고 값을 다시 정해 보세요." 투자: "5일째 전에 오래가는 투자를 해 보세요.") / 가계 "값을 바꾼 다음 날, 손님 수를 보고 재료를 고쳐 보세요." / 자유 "값과 투자를 상황에 맞게 직접 바꿔 보세요." / 책임 "'{사건 제목}'에서 아직 골라 보지 않은 쪽을 고르면 무슨 일이 이어질까요?"

## 학생용 성취기준 풀이(결과 화면에 짧게)
"사회 시간에 배우는 것: 시장에서 가계(손님)와 기업(가게)이 하는 일, 기업이 스스로 정할 수 있는 자유, 그리고 기업이 이웃과 사회를 위해 지켜야 할 책임이에요."
+ 작은 글씨: "근로자의 권리는 이 게임에서 다루지 않아요."

## 6. 화면 표시 보완 (2026-11-12, 사용자 피드백)
- 유형 막대: 나누는 기준값을 늘 막대 가운데(50%)에 두고 양쪽을 따로 늘린다. 막대 위 숫자는 뜻을 붙여 보여 준다("재료를 10그릇 넘게 바꾼 날 0일", "왕떡볶이보다 평균 389원 비싸게", "투자 0번").
- 별 카드: "해 본 것 ●○ + 그 근거 문장"과 "까닭 알기 ● + 인터뷰 문장"을 두 줄로 짝지어 보여 준다. 역할은 수요 읽기·가격 정하기·투자 통과 여부(✔/✖)를 함께 보여 준다. 위 안내: "해 본 것과 까닭 알기의 ● 개수를 더한 만큼 별을 받아요. ●가 하나도 없어도 별 1개는 있어요."
