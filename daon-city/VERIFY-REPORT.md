## 작업 범위

이번 재개 작업의 게임 수정은 `css/style.css`, `js/game.js`에만 했다. 검사 수정은 `tests/inspect-verify.py`, `tests/verify-browser.py`와 검사 전용 `tests/.python-packages/`에 한정했다. 결과물은 이 보고서와 `check-verify/`에 저장했다.

다른 게임, 루트 문서·설정, `shared-art/`, `guides/`, 그림 파일, 저장 키, 게임 규칙·균형은 변경하지 않았다. 이전 `check-verify/unchanged-before.json`의 해시로 `data.js`, `engine.js`, `city-art.js`, `people-art.js`, `paint.js`, `index.html`이 당시 상태와 같은 것도 확인했다.

| 낮음 | 이전 공용 Python Playwright 패키지 경로에 실행 가능한 패키지가 없어 검사 재개 불가 | `tests/.python-packages/`에 검사 의존성만 복구, 두 Python 검사에서 해당 경로 우선 사용 |

기존 수정도 재확인했다. 작은 카드·효과·요구 조건 글자 크기, 지도 최소 터치 영역, 화면 크기에 맞는 지도 계산, 건물 설치 후 키보드 초점 유지, 모달 초점 순환·복귀, 발전소 되돌리기 실패 안내, 사건 중 저장·이어하기를 현재 코드와 검사로 확인했다. 지난 실행의 `initial-run.json`에는 연결 오류와 페이지 예외가 남아 있었으므로 이를 완료 결과로 인정하지 않고 재검사했다.

검사 스크립트에는 숫자·배율·역사 비교 문구 줄바꿈 회귀 검사, 역사 점수 정합성, 생산 연타, 실제 오디오 생성, 실제 터치 입력을 추가했다. `--stage flows|edges|endings` 및 `--width`로 중단 구간만 다시 실행할 수 있다. 기존 `before-*` 자료는 덮어쓰지 않는다.

## 봇 실제 결과와 규칙 관련 제안

`tests/bots.js`의 원래 계획과 현재 규칙을 그대로 실행했다. a/b는 사건의 왼쪽/오른쪽 선택을 뜻하며, 모든 a가 무조건 좋은 선택인 것은 아니다.

| 계획 | a 선택 엔딩 / 역사 | b 선택 엔딩 / 역사 |
| --- | --- | --- |
| 균형 | 모두의 도시 / 7/7 | 조용한 초록 마을 / 3/7 |
| 역사 그대로 | 잿빛 수출왕 / 6/7 | 잿빛 수출왕 / 3/7 |
| 성장 | 멈춰 버린 도시 / 3/7 | 불공평한 부자 도시 / 3/7 |
| 교육 없음 | 열심히 자란 도시 / 3/7 | 열심히 자란 도시 / 3/7 |
| 환경 | 조용한 초록 마을 / 2/7 | 조용한 초록 마을 / 2/7 |

**중간 — 균형 제안:** `SPEC.md`의 대략적인 기대와 성장·교육 없음 봇의 결과가 다르다. 성장 봇은 초기 건설 횟수 때문에 교육 투자가 뒤로 밀리며, 교육 없음 봇은 낮은 생활·환경·공정 수치에서도 기본 엔딩 조건에 도달할 수 있다. 실제 결과는 정상 계산 결과이며 규칙 수치·판정 순서는 수정하지 않았다. 수업 의도에 맞는지 별도 검토할 것을 제안한다.

## 내용·교육·그림 검토

시대별 산업 성장 설명은 [국가기록원 산업발전](https://theme.archives.go.kr/next/economicDevelopment/developmentOfIndustry.do), [수출품 기록](https://theme.archives.go.kr/next/koreaOfRecord/export.do)과 대조했다. 1960년대 경공업 중심 수출과 1970년대 중화학공업 육성 흐름은 부합한다. 석유 파동의 시대는 [국가기록원 석유파동](https://theme.archives.go.kr/next/koreaOfRecord/gasoline.do), 외환 위기·금 모으기 운동은 [정책브리핑 외환위기극복 10년](https://www.korea.kr/news/policyNewsView.do?newsId=148682448)과 대조했다.

1980년대 자동차·전자제품 수출 확대와 1990년대 반도체 성장도 같은 국가기록원 수출 자료와 부합한다. 2000년대 인터넷 보급은 [2002년 초고속인터넷 정책 자료](https://www.korea.kr/archive/governmentView.do?newsId=148738102), 2010년대 한류는 [신한류 형성 과정](https://www.korea.kr/news/policyNewsView.do?newsId=148896714), 2020년대 첨단 산업은 [2021년 반도체·배터리·바이오 산업 자료](https://www.korea.kr/news/policyNewsView.do?newsId=148887704)와 대조했다. 대표 산업의 시대 흐름에서 명백한 사실 오류는 확인하지 못했다.

- **낮음 — 표현 제안:** “나라에 달러가 바닥났어요!”는 외환 위기를 쉽게 설명하는 비유이나 달러가 문자 그대로 0이 되었다는 오해를 줄 수 있다. 수업에서는 쓸 수 있는 외화가 부족해졌다는 뜻으로 보충 설명할 것을 제안한다. 원문 수정 없음.
- **낮음 — 용어 제안:** 중화학 공업·외환 위기·탄소·공정·콘텐츠 같은 말은 6학년 수업에서 짧은 풀이가 있으면 좋다. 게임에 설명 문구를 늘리지는 않았다. 즉시 수정해야 할 명백한 맞춤법 오류는 확인하지 못했다.
- **낮음 — 그림 스타일 제안:** 신문·사건의 회화풍 그림과 건설·튜토리얼의 페이퍼컷 SVG는 스타일 차이가 있다. 그림 늘어남은 확인되지 않았으며 실제 지도 조작에는 SVG가 사용된다. 통일 여부는 취향·그림 교체 영역이므로 제안만 남긴다.
- 연대 구분은 각 산업의 최초 등장 연도를 뜻하기보다 시대별 대표 성장 흐름으로 이해해야 한다. 전체 교과서와의 문장별 대조까지 한 것은 아니다.

## 화면 기록과 재실행

스크린샷은 모두 `daon-city/check-verify/`에 있다. 5개 크기의 건설 화면, 휴대폰의 역사 카드·엔딩 6종, 도감·설정, 타이틀·신문·튜토리얼 및 그림 대체 등의 대표 캡처를 직접 열어 확인했다. 전체 캡처에는 DOM 기반 글자 크기·터치 영역·가로 넘침·숫자 줄바꿈 검사도 적용했다. 태블릿·크롬북 크기의 건설 화면은 세로 스크롤 없이 조작 버튼과 지도가 화면 안에 들어왔고 휴대폰 지도 타일은 45px로 확인됐다.

- `before-*`, `before-metrics.json`: 지난번 수정 전 비교 자료
- `inspect-*`, `inspect-metrics.json`: 재실행한 초기 화면
- `<너비>x<높이>-*.png`: 실제 UI 흐름과 엔딩 화면
- `results.json`: 최종 전체 검사 결과
- `edges-results.json`: 재개 중 독립 엣지 검사 결과
- `endings-results.json`: 엔딩 30개 조합·도감 검사 결과
- `flows-before-server-interruption.json`: 5개 흐름 완료와 이후 서버 연결 실패를 함께 보존한 원본. 최종 `results.json`에는 이 실패의 위치와 재검사 결과도 명시했다.
- `initial-run.json`: 지난번 미완료 결과. 최종 통과 증거가 아님

```powershell
node daon-city/tests/engine-check.js
node daon-city/tests/bots.js
& 'C:/Users/hyunseung/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' -X utf8 daon-city/tests/inspect-verify.py
& 'C:/Users/hyunseung/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' -X utf8 daon-city/tests/verify-browser.py
# 예: 엣지만 다시 검사
& 'C:/Users/hyunseung/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' -X utf8 daon-city/tests/verify-browser.py --stage edges
```

로컬 서버는 기존 `http://localhost:8790/`를 사용했다. 새 서버를 만들거나 다른 작업의 서버를 종료하지 않았다. Chrome 실행·검사 패키지 접근이 제한되는 로컬 환경에서는 해당 실행 권한이 필요하다.

## 남은 문제와 검증 한계

검사한 범위에서 미해결 높은 심각도 버그는 없다. 남은 것은 위의 규칙 균형·용어·그림 스타일 제안이다. 게임 규칙이나 글·그림을 바꾸는 작업으로 확대하지 않았다.

실물 iPad/Safari·Android 브라우저와 실제 스피커 청취는 검사하지 않았다. 터치는 Windows Chrome의 실제 터치 이벤트를 사용했고 소리는 WebAudio 음 생성 여부로 검증했다. 서버가 다시 중단되면 검사 실행도 영향을 받으므로 중간 연결 실패 기록을 삭제하지 않았다.
