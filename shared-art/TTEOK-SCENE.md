# 떡볶이 타이쿤 장사 장면을 그림으로 바꾸기 (Codex 작업 지시)

## 목표
선생님 의견: "가게랑 손님 오는 장면이 너무 허접하다." 장사 화면의 거리 장면(지금 `tteok-tycoon/js/tycoon-art.js` 의 SVG `scene()`)을
**타이틀·엔딩 그림(`shared-art/tteok/title.webp`, `end_*.webp`)과 같은 구아슈 그림**으로 바꾼다. 손님 아이들이 걸어가는 움직임은 그대로 살린다.

## 1) 그림 만들기 — 내장 image_gen 만 (코드/SVG/PIL로 그리기 금지. 자르기·배경 지우기·WebP 변환만 PIL 허용)
공통 스타일: `IMAGES.md` 의 공통 문장 + 먼저 `tteok/title.webp`, `tteok/end_best.webp`, `people/shopkeeper.webp` 를 열어 보고 화풍·색·사장님 모습(여자, 빨간 두건, 흰 앞치마)을 똑같이. 글자·숫자·로고 없음(간판은 빈 판이나 떡볶이 그릇/왕관 그림만).
- `tteok/street.webp` (1600×900): 오후의 다온초 앞 거리. **왼쪽 35%** = 우리 작은 떡볶이 가게(빨강·흰 줄무늬 차양, 큰 떡볶이 판이 있는 계산대, 사장님이 계산대 뒤에), **가운데 30%** = 뒤쪽에 학교 정문·건물, 앞쪽은 비어 있는 넓은 인도(아이들이 걸어 다닐 자리), **오른쪽 35%** = 크고 번쩍이는 검정·금색 체인점 '왕떡볶이'(왕관 간판). 아래쪽은 인도와 도로 조금. **사람은 사장님 말고 아무도 없음.** 가게 입구 두 곳이 또렷이 보이게.
- 손님 아이 스프라이트 `tteok/kid_0.webp` … `kid_7.webp`: 초등학생 8명(남4·여4, 다양한 머리·옷·가방), 전신, 3/4 옆모습으로 걷는 자세, 같은 크기(키 약 320px). **투명 배경**(단색 크로마 배경으로 만들어 PIL로 지우고 가장자리 정리).
- 장면 위에 얹는 투명 스프라이트: `tteok/sp_truck.webp`(초록 푸드트럭, 노란 차양, 빈 간판), `sp_chairs.webp`(빨간 둥근 의자 3개), `sp_staff.webp`(앞치마 입은 알바생이 손 흔드는 모습), `sp_cheese.webp`(치즈가 듬뿍 올라간 떡볶이 판 — 계산대 위에 얹을 크기), `sp_clean.webp`(반짝이는 '위생 우수' 느낌의 빈 액자 + 반짝이, 글자 없음).
- 원본 `raw/`, `manifest.json` 갱신. 직접 열어 보고 글자·워터마크·잘림·지저분한 가장자리 있으면 다시.

## 2) 게임에 연결 (`tteok-tycoon/`)
- `tycoon-art.js` 의 `scene(o)` 를 그림판으로: 배경 `street.webp` 위에 상태에 따라 `sp_chairs`(o.chairs), `sp_staff`(o.staff), `sp_cheese`(o.cheese), `sp_clean`(o.clean), `sp_truck`(o.truck) 를 알맞은 자리에 얹는다. 비 오는 날(o.rain)은 그림 위에 CSS/SVG 빗줄기 + 살짝 어둡게. 그림을 못 불러오면 **지금의 SVG 장면 그대로**(js/paint.js 방식).
- 장사 애니메이션(`game.js` business)의 아이는 `kid_{n % 8}` 그림으로. 가는 곳(target)을 새 그림의 우리 가게 입구·왕떡볶이 입구·푸드트럭·화면 밖(그냥 집에 감)·다 팔려서 돌아서는 자리로 다시 맞춘다. 걸어가는 동안 살짝 통통 튀는 걸음, 우리 가게 쪽으로 가면 왼쪽을 보도록 좌우 뒤집기. 말풍선은 지금처럼.
- 타이틀 화면은 이미 그림이므로 그대로. 엔딩 그림도 그대로.
- 글씨 크기·버튼·게임 규칙·data.js·engine.js 는 건드리지 않는다.

## 완료 조건
- Playwright 로 장사 화면을 1366×768, 1024×768, 768×1024, 390×844 에서 찍기: 기본 / 의자·알바·치즈·위생 모두 산 상태 / 비 오는 날 / 푸드트럭 있는 날(엔진 상태를 localStorage 저장본으로 만들어 이어하기). `shared-art/check/tteok-scene-*.png` 로 저장하고 직접 열어 보며 아이들이 가게 문으로 가는지, 겹침·잘림 없는지 확인. 콘솔 오류 0.
- 그림 파일 이름을 일부러 틀리게 해서 SVG 대체가 되는지 확인.
- 끝나면 바꾼 파일, 새 그림 목록, 확인 결과를 짧게 보고. 사용량 한도에 걸리면 멈추고 어디까지 했는지 보고.

## 건드리면 안 되는 것
다른 게임 폴더, `tteok-tycoon/js/data.js`·`engine.js`·`tests/`, 기존 그림 파일(새 파일만 추가), `IMAGES.md`.
