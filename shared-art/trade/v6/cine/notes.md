# 시네마틱 장면 제작 기록

## 완료 상태

요청한 12장 모두 완료. 최초 생성은 지정 순서대로 진행했고 각 결과 직후 원본 PNG와 WebP를 저장했다. 사용량 제한에 의한 중단 없음.

## 제작 및 규격

- 이미지 제작과 보정: 내장 image_gen만 사용, 총 17회(최초 12회 + 보정 5회).
- 참고: trade/title.webp, trade/end_king.webp, trade/end_island.webp, trade/end_rawOnly.webp, trade/v6/home_3.webp를 생성 전에 모두 열어 확인했다.
- 원본 PNG: 모두 1672×941. 도구가 반환한 16:9 근사 비율(픽셀 반올림) 원본을 raw/<id>.png에 그대로 보관했다.
- 최종 WebP: 모두 정확히 1600×900(16:9), quality=85, LANCZOS 리사이즈.
- Pillow는 리사이즈와 WebP 변환에만 사용했다. 그리기·합성·크롭·색상 보정 없음.
- 코드 및 지정 폴더 밖의 사용자 파일 수정 없음. 도구가 자동 저장한 생성 이미지는 도구 기본 경로에 남아 있다.

## 검수 및 보정

- res_food: 수확기 옆 명판의 글자처럼 보이는 무늬를 무표식 금속으로 보정(1회).
- res_tech: 입체 렌더 느낌과 고전적 도시 배경을 붓질이 뚜렷한 회화풍 및 현대식 스카이라인으로 재생성(1회).
- ev_storm: 누락된 번개를 추가하고 화물선을 현대식 컨테이너선으로 재생성(1회).
- ev_market: 주황색 기름통에 생긴 작은 흰 글자/숫자 표시 제거(1회).
- ev_pirates: 화물선 굴뚝의 로고처럼 보이는 문양 제거(1회).
- 모든 최종 WebP를 실제로 열어 배·기계·통·천막·상자의 표식과 전체 구도를 육안 확인했다. 읽히는 글자, 숫자, 로고, 워터마크가 보이지 않는다.
- 400×225 축소본도 12장 모두 열어 어두운 장면의 식별성과 중심 소재를 확인했다.
- 최종 WebP 규격·파일 디코딩 및 원본 PNG 존재·최소 크기 검사를 통과했다.
- 레터박스/자막 여유를 프롬프트에 지정했고 중심 행동과 얼굴의 식별성을 확인했다. 일부 배경 구름·불꽃·기계 끝부분·전경 다리 등은 화면 가장자리에 걸친다.
- 게임 코드와 실제 영상 재생은 변경하거나 시험하지 않았다.
- 폐기된 최초 시안은 최종 raw 파일로 대체했다. 아래에는 보정 전후 실제 사용 프롬프트를 모두 남겼다.
- 기록은 UTF-8로 저장했다. 변환용 임시 Python·Pillow·검수 축소본·캐시는 최종 정리 대상이다.
